| 하는 일 | 요청이 올 때마다 화면에 넣을 내용을 새로 만들어 보내 줌 | 서버가 보내 준 것을 화면에 그리고, 화면 위에서만 꾸밈 |
| 코드가 있는 곳 | app.py 같은 서버 코드 파일 | HTML 안의 \<script\> 태그, .js 파일 |
| 앱을 끄면? | 페이지 자체가 안 열림 (502 오류) | 앱과 상관없이 이미 받은 화면에서 그대로 동작 |

 

| \[참고\] 주방에서 새로 만들어 내오면 서버가 한 일, 테이블 위에서 손님이 접시 위치만 바꾸면 브라우저가 한 일입니다. 이번 평가는 "주방이 실제로 돌아가는가"를 봅니다. |
| :---- |

**② 쉽게 구분하는 방법 \- 2단계**

**1단계. 그 기능을 만드는 코드가 어느 파일에 있는지 찾습니다.**

· app.py 같은 서버 코드 파일 안에 있다  →  서버

· HTML 안의 \<script\> 태그나 .js 파일 안에 있다  →  브라우저

 

**2단계. 그래도 헷갈리면 터미널에서 아래를 쳐서 확실하게 확인합니다.**

| curl http://127.0.0.1:앱포트 sleep 3 curl http://127.0.0.1:앱포트 |
| :---- |

 

| \[참고\] curl 은 브라우저가 아니라 "글자만 받아오는 명령"이라 자바스크립트를 실행하지 않습니다. 그러니 그 값이 curl 결과에 나오면 서버가 만든 것, 안 나오면 브라우저가 만든 것입니다. |
| :---- |

 

**③ 자주 나오는 기능 분류 (참고용)**

| 기능 | 일하는 곳 | 왜 그런가 |
| ----- | :---: | ----- |
| 페이지를 열 때마다 현재 시각이 나옴 | 서버 | 서버 컴퓨터의 시계를 읽어서 글자로 만들어 보내 줌 |
| 방문자 수가 1씩 올라감 | 서버 | 숫자를 서버가 기억하고 있다가 1을 더해서 보내 줌 |
| 이름을 입력하면 인사말이 나옴 | 서버 | 입력한 값이 서버로 가고, 서버가 문장을 만들어 돌려줌 |
| 오늘의 급식·명언을 골라서 보여줌 | 서버 | 서버에 저장된 목록에서 하나를 골라 보내 줌 |
| 글을 쓰면 저장되고 목록에 쌓임 | 서버 | 서버가 파일이나 DB에 적어 두었다가 다시 꺼내 줌 |
| 로그인하면 내 이름이 나옴 | 서버 | 아이디·비밀번호를 서버가 확인하고 결과를 만들어 줌 |
| 버튼을 누르면 색이 바뀜 | 브라우저 | 서버에 물어보지 않고 화면에서만 바뀜 |
| 시계가 1초마다 째깍째깍 움직임 | 브라우저 | 내 컴퓨터 시계를 자바스크립트가 읽어 화면만 갱신함 |
| 메뉴가 스르륵 펼쳐짐 / 애니메이션 | 브라우저 | 화면 효과일 뿐, 서버는 아무 일도 하지 않음 |
| 사진이 자동으로 넘어감 (슬라이드) | 브라우저 | 이미 받아 둔 사진을 바꿔 보여 줄 뿐 |

 

| \[주의\] 화면이 화려하게 움직여도, 서버가 하는 일이 하나도 없으면 정적 배포로 판정되어 0점입니다. '움직이는 화면'과 '서버가 일하는 것'은 다릅니다. |
