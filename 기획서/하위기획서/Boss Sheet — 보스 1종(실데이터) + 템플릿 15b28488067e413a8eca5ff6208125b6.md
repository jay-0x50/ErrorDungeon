## 1. 보스 1종(실데이터) — “무너진 장군, 도윤”

| 항목 | 내용 |
| --- | --- |
| 이름 | 무너진 장군, 도윤 |
| 지역/등장 | 1지역 ‘폐성 외곽’ 던전 최심부 |
| 콘셉트 | 장창 + 중갑. 긴 리치, 느리지만 추적이 강한 콤보 |
| 체력/강인도 | HP 6200 / Poise 220 |
| 페이즈 | P1 기본 / P2(HP 50% 이하) 광폭 + 창에 속성 부여 |
| 약점/내성 | 약점: 번개 / 내성: 출혈(축적 -30%) |
| 처치 보상 | 12000 Souls, 고유 무기 ‘도윤의 장창’, 던전 출구 쇼트컷 해금 |
| 체크포인트 | 보스룸 40m 전 ‘폐성 화톳불’ |

### 1.1 공통 규칙

- 패턴마다 ‘텔(예고 동작)’을 명확히 둔다.
- 큰 패턴 후에는 확정 빈틈(최소 0.8초)을 준다.

### 1.2 패턴 목록(P1)

1. **창 2연 찌르기**
    - 텔: 창을 허리 아래로 낮추고 발을 당김(0.4초)
    - 판정: 전방 직선 2타, 2타는 약간 추적
    - 대응: 1타에 좌/우 회피 → 2타 후 빈틈 0.9초
2. **쓸어베기(좌→우)**
    - 텔: 왼쪽 어깨를 크게 열며 창을 뒤로 뺌
    - 판정: 반원 범위, 가드 시 스태미나 큰 소모
    - 대응: 뒤로 거리 벌리기 또는 타이밍 회피
3. **점프 내려찍기**
    - 텔: 무릎을 굽히며 위로 도약(0.5초)
    - 판정: 착지 지점 원형 충격파(근거리)
    - 대응: 착지 직전 구르기(무적) 또는 2회 연속 회피
4. **방패 밀치기(가드 브레이크 유발)**
    - 텔: 방패를 앞으로 세우고 한 걸음 전진
    - 판정: 근거리 1타, 가드 시 추가 스태미나 소모
    - 대응: 거리 유지 / 패링 가능(난이도 높음)
5. **후퇴 찌르기(간격 벌리기)**
    - 텔: 뒤로 반걸음, 창 끝을 앞으로 세움
    - 판정: 뒤로 이동하며 1타
    - 대응: 무리한 추격 금지, 후딜 0.6초
6. **3연 콤보(찌르기→쓸기→찌르기)**
    - 텔: 창을 수직으로 들어 올림
    - 판정: 3타, 마지막이 강공격급
    - 대응: 1~2타는 회피, 3타 후 확정 빈틈 1.2초

### 1.3 패턴 목록(P2 추가/강화)

1. **번개 창 돌진**
    - 텔: 창에 번개 이펙트(0.7초 충전)
    - 판정: 직선 돌진 1타 + 잔류 번개 장판 3초
    - 대응: 옆 회피(타이밍) + 장판 밖으로 이동
2. **광폭 연타(5타)**
    - 텔: 포효(0.6초) 후 상체를 낮춤
    - 판정: 근거리 5타, 추적 높음
    - 대응: 2타 후 ‘뒤구르기 2회’로 탈출 또는 패링(리스크)
    - 빈틈: 종료 후 1.0초

### 1.4 구현 체크리스트

- 각 패턴: 애니메이션 몽타주/상태 전환/히트박스 타이밍 테이블
- 페이즈 전환: 컷신 없이 1초 경직 + 버프 적용(속성)
- 보스 재도전 루프: 사망/휴식 시 보스 HP/패턴 초기화
